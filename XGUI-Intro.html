Why XGUI

别再为每个窗口
重新拼一套 GUIStyle

编辑器工具的门槛往往不在功能，而在外观：控件零散、状态缺失、风格各写各的，做着做着就成了“能跑就行”。

手工拼样式 每个窗口一套

  • ✕每个控件手写 GUIStyle，normal / hover / pressed 三态逐个对齐
  • ✕字体、图标、底板贴图自己找，风格在窗口之间漂移
  • ✕弹窗只能用系统 DisplayDialog，样式完全脱离工具自身风格
  • ✕多选时混合态要自己判 hasMultipleDifferentValues，还得逐个回写

XGUI 一套皮肤贯穿

  • ✓内置 XGUI.guiskin，所有控件共用一套皮肤，调用即统一
  • ✓17 主题色 × 5 种填充，80 套预制底板贴图，颜色可枚举也可直接传
  • ✓dialog_* 三形态弹窗，主题色可传任意 Color，风格与主窗口一致
  • ✓把 SerializedProperty 直接交给控件，混合态显示 — 并可一键统一
Two APIs

自动排版与精确绘制，
同一个窗口里也能混用

两套 API 功能对等：想少写 Rect 就用 layout_*，想完全掌控位置就用 gui_*。

layout_*
自动布局

基于 GUILayout / EditorGUILayout 的流式排列，窗口缩放自动跟随，适合设置面板与 Inspector。

  • 分组、开关、滑块、按钮一行一个调用
  • editor_layout_group_* 版会返回分组 Rect，便于自绘
  • 间距与弹性占位内置，无需手算高度
XGUI.layout_slider(title: "速度", prop: speed, left: 0, right: 100);
gui_*
精确绘制

基于 Rect 的精确摆放，位置尺寸完全可控，适合自绘面板、叠加布局与卡片、虚拟列表。

  • 区域、背景块、卡片、色相条等只在 gui_* 提供的组件
  • gui_scrollview<T> 只绘制可见项，带高度缓存
  • 与 layout_* 混用时用 gui_area_start 圈出独立区域
XGUI.gui_area_start(rect); ... XGUI.gui_area_end(rect);
Features

从皮肤到动效，
都在一个包里

零配置：首次调用自动加载皮肤、字体与纹理缓存。资源全部走 AssetDatabase，包模式与 Assets 模式都能定位。

17 主题 × 5 填充

深空灰、亮金色、工业蓝、健康绿… 配合实体 / 边框 / 缺口边框等 5 种容器填充，共 80 套预制底板。

20 余种控件

分组、按钮、横幅、帮助框、输入、开关、滑块、下拉、颜色、曲线、工具栏、进度、状态、卡片、虚拟列表、路径选择器。

三形态弹窗

标准对话框、名称 + 描述提交框、可拖动排序的列表选择框；1~5 个按钮自动布局，6 种对话框类型。

EditorPlayer 动效预览

数值插值、序列帧、音效预览三件套，共用 EditorApplication.update 驱动，无需进入 Play Mode。

43 种缓动曲线

标准缓动加 Shake / Flash / Glitch 等特效曲线，按 2~100 个关键帧采样并写入切线。

SerializedProperty 原生

开关、滑块、下拉、颜色、属性框直接吃属性对象；多选时自动显示 — 混合态并支持一键统一。

Get Started

四行代码，先跑起来

新增一个 EditorWindow，把控件换到 XGUI 的调用即可；已有的布局逻辑不用重写。

my_window.cslayout_* 自动布局
using SevenStrikeModules.XGUI.Editor;
using SevenStrikeModules.XGUI.Runtime;
using UnityEditor;
using UnityEngine;

public class my_window : EditorWindow
{
    private bool fold = true;
    private bool enable;
    private float speed = 10f;

    [MenuItem("Tools/XGUI/示例窗口")]
    private static void Open()
        => GetWindow<my_window>("XGUI 示例");

    private void OnGUI()
    {
        fold = XGUI.layout_group_start(
            type: XGUIContainerType.Vertical,
            bg_fill: XGUIGroup.缺口纯色边框,
            bg_color: XGUIColor.亮白,
            title: "基础设置",
            padding: new RectOffset(10, 10, 20, 15),
            foldout: fold);

        if (fold)
        {
            enable = XGUI.layout_toggle(
                title: "启用模块",
                prop: enable,
                title_width: 100);

            speed = XGUI.layout_slider(
                title: "速度",
                prop: speed,
                left: 0, right: 100,
                title_width: 100);

            if (XGUI.layout_button(
                text: "应用设置",
                bg_fill: XGUIGroup.实体,
                bg_color: XGUIColor.亮金色))
                Debug.Log($"{enable} / {speed}");
        }

        XGUI.layout_group_end(XGUIContainerType.Vertical);
    }
}
my_component_editor.csSerializedProperty
using SevenStrikeModules.XGUI.Editor;
using SevenStrikeModules.XGUI.Runtime;
using UnityEditor;

[CustomEditor(typeof(my_component))]
public class my_component_editor : Editor
{
    public override void OnInspectorGUI()
    {
        serializedObject.Update();

        XGUI.layout_banner(
            bg_fill: XGUIGroup.实体,
            bg_color: XGUIColor.深空灰,
            bg_height: 30,
            title_text: "MyComponent 设置",
            title_size: XGUIFontSize.B);

        XGUI.layout_toggle(title: "启用",
            prop: serializedObject.FindProperty("enable"), title_width: 80);

        XGUI.layout_slider(title: "强度",
            prop: serializedObject.FindProperty("strength"), left: 0f, right: 5f, title_width: 80);

        serializedObject.ApplyModifiedProperties();
    }
}

安装

打开 Window > Package Manager，点 + → Add package from git URL…

1粘贴 Git 地址，等待编译完成
https://github.com/SevenStrike/XGUI.git?path=com.sevenstrike.xgui
调用 XGUI 控件的脚本必须位于 Editor 目录或 Editor-only 程序集，否则会因程序集隔离无法引用。

示例资产以 UPM Sample 形式提供，导入后位于 Assets/Samples/XGUI/1.0.0/Demo。

其它安装方式

  • 本地磁盘：Add package from disk…，选 com.sevenstrike.xgui/package.json
